# Adaptive Career Agent

**Candidate: v3 plus monthly performance checks; one local 48-month completion at L4, 49.33/100.** In the intended routine, at the first story decision each month the agent reuses the observation and context, checks the previous priority against returned feedback and trends (or unknown), and chooses one priority from the latest review and present needs. Month, observed progress or unknown, and current priority go in that first ordinary action's notes. Offered story choices and quarterly Energy/main-action comparisons use the priority, subject to v3's survival and persistent-warning checks; explain any competing need. Contrary results prompt reconsideration. A goal does not require extra workload. Formal reviews stay six-monthly; add no monthly grade, Energy, action, phase, checkpoint-only observation/log call or repeated plan recital. Stop at the ending. The 64.52 result below belongs to unchanged v3 on `main`; higher reviews and earlier promotions are not yet demonstrated.

Team: Jon8652's team (carried forward from the verified preliminary entry).

One JiuwenSwarm 0.2.4b3 agent, with manifest mode `agent`, aims to complete a balanced 48-month career. Two prose Skills provide distinct decision procedures:

- `event-decisions`: compare the current story's legal options against wellbeing, development needs, warnings, and uncertain longer-term consequences.
- `quarterly-planning`: allocate the observed Energy budget, choose a main action, and adapt priorities from performance feedback.

Both use current observations, the public handbook, and feedback from the current run. There are no executable Skills, event answer tables, private formulas, or assumed failure thresholds. Use official notes/logs when needed; no workspace memory, memory tools or embeddings. See the design documents for reasoning and limitations.
