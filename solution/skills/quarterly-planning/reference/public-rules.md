# Public rules card

Published facts only. Current official observations take precedence if settings differ. This card contains no event answers, operating-policy bands, numerical action deltas or hidden formulas.

Sources: official participation repository `docs/handbook.rst` and `docs/rules.rst`, verified 29 October 2026. [Handbook](https://techarena-career-sim.readthedocs.io/en/latest/handbook.html), [public rules](https://techarena-career-sim.readthedocs.io/en/latest/rules.html).

## Cadence and bounds

48 months; up to 3 story events per month by default. Quarterly budget: 3 Energy, no carry-over. One separate main action per quarter or none. Reviews and promotion windows every 6 months; exact criteria unpublished. Health and Dignity range 0-10. Skill, Network and Output are published as nonnegative; Wealth may be negative. Always use the actual returned state.
